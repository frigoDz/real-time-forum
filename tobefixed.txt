Global document and window event listeners are attached during view initialization (
forum.js
, 
admin.js
) without removing prior listeners, causing duplicate executions when navigating between routes.
4. API & Data Payload Mismatches
Gender Payload: 
register.js
 sends "Male" / "Female", while the backend API expects lowercase "male" / "female".
State Pollution: IsValidId in 
post-details.js
 is a module-level variable that retains state across different post route changes.
Hardcoded Avatars: Header, mobile menu, and post creation boxes hardcode "U" as the user avatar initial rather than using the logged-in user's nickname.
